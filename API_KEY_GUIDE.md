# ACI Customer Assistant — Gemini AI Guide

Gemini powers the AI customer assistant, sales forecasting, and voice search features.

## Add your Gemini API key

1. Open [Google AI Studio](https://aistudio.google.com/app/apikey).
2. Create or copy your Gemini API key.
3. Open the **Gemini API Key Guide** inside ACI Customer Assistant.
4. Paste the key into the secure key field and select **Save key**.

Keep your key private and do not share it publicly.
